## 1. 背景与目标

第四阶段已经完成中英文界面、程序设置、转换预设与批量转换的主体开发。用户实际使用未发现明显问题；源码审查发现多通道文件发布、CLI 单文件预设筛选及 GUI 预设应用的局部缺陷。阶段验收记录中，精简配置构建及若干运行用例通过，完整 libmseed 配置受开发环境限制，批量停止及部分界面操作仍待专项验收。

本阶段将上述遗留问题作为前置修复任务，不再安排独立的大型修复阶段。完成基础修复后，在现有格式转换工具上增加单通道地震动查看、时域参数、频谱、反应谱和结果导出能力。REST、MSL 中已有算法优先采用选择性拷贝和本地适配，避免重复研究和编写成熟算法。

本阶段的目标不是建设另一个 REST，也不是把 GMTools 改造成通用数值算法库。应保持单文件、独立 Trace、简单明确的输入输出契约及轻量的 GUI 使用方式。

### 2.1 不变的项目原则

- 保留 `gmtools_core`、`gmtools`、`gmtools_gui` 目标、xmake 构建和现有 `FileData / Trace` 基本结构。Core 不依赖 Qt。
- 一个 Trace 是独立的分析对象；不要求跨通道相同采样率、时间范围或样本数，不自动拼接、同步、重采样或填补缺段。
- 现有 Reader、Writer、单位换算、标定、Profile、自描述文本和批量转换契约保持兼容；仅对明确缺陷作必要修复。
- 分析以当前已经读取、标定和解释的 Trace 为输入，只读计算。分析选项只作用于临时数据，不修改 Trace 样本、原文件、导出勾选、当前单位或已有处理历史。
- 不直接依赖 REST、REST GUI 或完整 MSL；不添加其 submodule、不跨仓库 include、不链接其编译产物，不修改、构建清理或提交其他项目。所有新增及修改文件均位于 EETB 项目范围内。
- 本阶段不新增文件格式、不建设跨文件分析工作流、不做多通道联合分析、结构模态识别或响应重构。滤波、重采样、完整基线校正及可修改波形的处理工作区留待后续。
- 不建立大量自动化测试，不自行启动程序测试、GUI、截图或视觉检查，不自行提交 Git；允许必要的静态核查和编译。本文的验收设计不等于测试执行授权。保留用户未提交改动，输出及临时数据置于本项目忽略的构建目录。

### 2.2 开发前置核查与默认技术决策

先核对 `git status`、最新提交及现有文档；如果实际基线已变化，依据源码确认哪些 M0 问题已修复，不重复实施。检查现有 libmseed、Qt SDK、Linguist、Eigen 可用性及对应许可。缺少 libmseed 不阻塞精简配置的分析开发；不得声称已验证完整配置。

本阶段采用以下可直接执行的默认方案：

1. 直接使用 Eigen 的必要头文件和算法能力（FFT、固定尺寸矩阵指数），不引入完整 MSL。优先复用已有可用的 Eigen 3.x 版本，通过 xmake 声明依赖，记录实际解析版本。不能将其他项目的 Eigen 绝对路径作为正式依赖入口。
2. 保留现有 QPainter 多通道波形概览；详细分析窗口第一版也优先使用 Qt/QPainter，通过小型可复用二维曲线控件实现必要交互。参考 REST GUI 的绘图设计经验，不直接复制 GPL 绘图代码或引入 QCustomPlot。若必须引入 QCustomPlot 或其他许可影响较大的绘图库，应单独取得用户认可；不阻塞 M0–M4、M7 的 Core/CLI 工作。
3. 默认分析原时程，不隐式去均值、去趋势或积分；仅 Welch PSD 默认分段去均值，且明确显示这一参数。加速度推算 PGV/PGD 必须主动选择积分方案。
4. 本轮建议保持现有版本管理方式，不自动发布或修改许可证；本地移植授权与公开再分发授权分开核查。

以上是为使开发能够直接启动而设定的第一版实施约定；不要求为未来尚未使用的能力预先设计复杂架构。

## 3. M0：第四阶段遗留问题修复

### 3.1 F1：多通道发布及文件保护（必做）

当前 `src/core/files.cpp` 中 `publish_outputs()` 在每次发布前调用 `validate_targets(plan, {}, overwrite, {}, diagnostics)`。这里重新检查整个计划，默认不覆盖模式下第一个目标成功写出后，会被下一次完整检查视为既有目标，导致后续通道未写出。同时，发布时传入的保护路径和批次预留列表为空，弱化了原来规划阶段的保护。

修复要求：

- 保留编码前完整计划预检、逐通道编码暂存及实际发布机制。完整计划内的目标必须互不冲突，考虑规范化路径、已有文件的等价路径、平台大小写语义及安全命名可能造成的重名。
- 实际发布每一个目标前，只复核即将发布的目标，不能将本任务已经写出的其他目标当作既有冲突。将原始输入保护和其他任务预留/已发布目标保护传递至发布路径。区分当前计划自身的预留与其他计划的预留，避免本计划与自己冲突。
- 覆盖开关只允许替换用户许可的外部普通目标文件，不能覆盖任何批次原始输入、链接指向的原件或已由其他批次内任务占用的目标。单文件仍保护自己的输入。尽量保留现有平台原子不覆盖发布路径；不得宣称普通路径预检可彻底防御恶意并发文件系统更改。
- 全部通道编码成功后才开始发布；编码失败应零发布。发布阶段失败时保留已经实际生成的文件，返回真实 `written` 和 Partial 状态，不虚构回滚或全部成功。明确失败计划的预留释放策略，至少已发布目标不得释放供后续覆盖。
- 同时适用于原有 `export_file()` 和 `convert_batch()`；不分别编写两套命名或保护逻辑。

最小验证：使用一个有明确列布局及三个通道的小 CSV，在空目标目录默认不覆盖时分别经 `convert`、`batch` 导出三份文件；核对内容、文件数量、原文件哈希。检查重复目标、覆盖、批次中尚未处理的原件，以及多通道编码失败零发布。无需依赖标准 miniSEED。

### 3.2 F2：统一 CLI 单文件与批量的通道筛选（必做）

当前 `src/cli/main.cpp` 的 `convert` 在加载并覆盖预设后，没有将 `preset.selection` 应用到最终 `ExportOptions.channels`。`batch.cpp` 已实现按读取、标定后的物理量选择通道。

提取小型公共筛选函数（例如返回选中的 1-based Trace 索引及诊断），CLI 单文件和批量共同使用；GUI 可以复用相同规则映射为勾选状态。空结果必须明确失败，不得传入代表“全部通道”的空 `channels`。筛选在完整读取、标定和用户覆盖之后执行。

优先级明确为：显式 `--channel N`（仅单文件）优先于预设筛选，显式 `--select-all` 或 `--select-quantity` 覆盖预设规则；若同一命令同时显式指定 `--channel` 和选择规则，明确拒绝互斥参数。无预设时，`convert` 的显式选择规则也应真实生效（如 CLI 接受该参数）。批量仍拒绝文件特定的索引和时间、身份编辑。

检查 `ReadOptions.selected_channel` 当前的作用范围，确保需要在读取时对指定通道应用的单文件属性不被误施加到其余通道；不为了筛选而重写 Reader。

最小验证：构造或采用含混合物理量的可控样本，检查 `convert` 与 `batch` 同规则产生等价选择与数据；没有匹配通道时非零退出且零输出；显式索引与预设覆盖按上述语义生效。如无混合实录，允许分别用合成加速度、counts 文件验证选择与无匹配路径，真实武汉样本后补。

### 3.3 F3：GUI 预设应用与回退

`MainWindow::apply_preset()` 目前先修改 Writer、目标格式及输出单位，再确认并重新解析；取消或解析失败时只恢复部分内部状态。

改为候选配置校验、确认与解析、统一提交的过程：

- 载入后先核查当前构建是否支持目标格式及明确的输入格式；不可用时明确提示，不静默换成其他格式。
- 未打开文件时可以保留待应用预设；打开后从原始字节按候选 ReadOptions 解释，不在现有已标定样本上重复处理。
- 用户取消确认、导入配置对话框或解析失败时，原 Trace、读写参数、目标格式、输出单位、通道勾选、未导出编辑状态及当前预设显示保持一致。不在确认前修改生效设置。
- 成功后先更新数据及通道选择，再刷新适用的输出单位与格式选项，最终设置预设值。没有输出单位的预设必须清除旧值（保持输入单位），不能因旧下拉框内容而意外改变预设；不兼容单位给出明确提示或阻止不合法导出。
- 用户仍可在预设加载成功后手动调整参数；不把覆盖许可、单文件身份或历史波形偷偷保存到通用预设。

### 3.4 F4：批量任务结果与进度

当前 Core 结果已经保存每文件诊断、通道数、实际输出路径和批次级诊断；GUI 主要显示状态与数量，进度更新会复制整个 `BatchResult`。本轮局部优化：

- 批次级预检失败应明确显示诊断和未执行状态，不能仅显示“批次完成、0 失败”；完整结果显示实际输出路径、读取/选择通道数、Partial 及未执行原因。
- 安全停止请求后保留“完成当前文件后停止”提示，直至结束；运行时不允许关闭造成后台悬空。对窗口关闭、Esc、取消按钮等路径保持一致。CLI 非批量操作的 SIGINT 行为也应保持原有合理语义，不因批量停止机制无意吞掉中断。
- 进度通知优先传输变化项、当前阶段和汇总，不频繁复制全部历史诊断及任务列表；完成时一次传递完整结果。可以保留现有 Core 回调签名，在 GUI 适配侧构造轻量更新；不引入任务调度框架。
- 保持逐文件顺序转换、每文件失败隔离，不额外引入并行调度。

### 3.5 F5：构建和文档维护

检查 xmake 安装与打包时 `gmtools_zh_CN.qm` 是否确实位于可执行文件旁 `translations/` 或正式约定的资源路径；补齐安装规则（包括卸载一致性），确保普通构建与安装均能获得翻译。优先使用实际 Qt SDK 的 Linguist 工具，避免误用不匹配版本。按需要部署 Qt 自带中文翻译资源，缺失时保留明确回退行为。

核查历史文档重新编号后的仓库内部链接（尤其 README 与验收记录）；不批量重写历史内容。恢复标准 miniSEED SDK 后再核查完整构建。保留已知限制和样本许可说明。

## 5. 公共分析契约

### 5.1 输入与结果

分析以 `const Trace&` 为基本输入，所需参数由小型结构提供；计算结果独立返回。接口命名示例（非强制签名）：

```cpp
TraceStatistics calculate_statistics(const Trace& trace);
IntensityResult calculate_intensity(const Trace& trace, const IntensityOptions& options);
SpectrumResult calculate_spectrum(const Trace& trace, const SpectrumOptions& options);
ResponseSpectrumResult calculate_response_spectrum(const Trace& trace, const ResponseSpectrumOptions& options);
```

具体返回值可以包含 `Diagnostics`，或由统一边界捕获算法异常并转换为诊断。避免不同模块混用静默空值、异常与错误码；不适用指标须有明确状态/原因。结果应保留源通道名称、索引或标识、样本数、采样间隔（如有）、当前量/单位、实际分析参数、结果单位、必要的数值方法说明。不要为此复制整份 Trace 或保存完整原始样本副本。

- 检查空数据、NaN/Inf、无效 dt、非有限计算结果和参数上限。不因一项指标不可用而错误地拒绝其他可计算的指标。处理单点、全零、常值及短记录；不可用值采用明确状态或 JSON `null`，禁止伪造零结果、输出 NaN/Inf 或用任意极小值代替。
- 统计、峰值可在未知 dt/单位的样本上计算；时刻必须有 dt，否则显示采样点索引。频域与需要积分的指标要求合法 dt，反应谱及有工程物理意义的强度指标还要求物理量与单位匹配。
- 当前 Trace 中的 counts、未知量或未知单位不进行隐式标定，不将 counts 的峰值标为 PGA。FFT/PSD 可分析任意有限数值的等间隔 Trace（包括 counts）；轴单位反映真实输入标签或未知状态。
- 工程强度指标、积分及反应谱优先在临时 SI 数据上计算，使用现有 `unit_factor()`；不得重复标定。结果的展示换算使用相应量纲关系，不把 PSD 当作普通幅值换算（PSD 比例需平方）。
- 时间坐标默认以首样本为零，`t_i=i*dt`，区间跨度 `(N-1)*dt`；如果同时展示 `N*dt` 名义记录长度，应明确区分。绝对时间和相对起点仅在已知时用于信息显示，不推断未知时间。
- 默认分析整段 Trace，而不是当前缩放后的视口；本阶段不提供可修改波形的截取，缩放或选点不触发重新计算。将来支持分析区间时应明确区间、样本边界及时间基准，不改变此默认行为。

### 5.2 分析状态与结果有效性

GUI 和 CLI 使用同一套计算实现。分析结果与具体输入通道、数据修订状态、采样参数、量/单位和计算选项绑定；修改输入、重新解析、修改采样参数/量/单位或分析参数后，旧结果应失效或明确标记为旧结果。不能在当前通道上展示来自先前通道的结果。

不引入 REST Run、Dataset 或 SpectrumProduct 的完整生命周期管理。第一版允许仅保存当前窗口内最近计算结果；如果确有必要，使用小型缓存，避免对全部通道、全部参数永久缓存。不需要哈希全量样本来确认每次 GUI 交互，只需可靠的输入所有权及修订状态。

## 6. M2：时域统计与地震动强度指标

### 6.1 基本统计

| 指标 | 定义/要求 |
|---|---|
| N、dt、fs、跨度 | 保持 Trace 原有语义，缺失项明确不可用 |
| 最小值、最大值 | 原始带符号值 |
| 绝对峰值 | `max(abs(x[i]))`；同时保留峰值对应带符号值 |
| 峰值位置 | 相同峰值取首次出现；内部 0-based，界面及对外索引明确统一为 1-based |
| 峰值时刻 | 相对首样本的经过时间；若 dt 未知则不提供 |
| 均值、标准差、RMS | 默认总体标准差（除以 N），RMS 为 `sqrt(sum(x²)/N)` |

采用可靠的累加/方差算法并检查极端幅值下的溢出，避免 `E[x²]-E[x]²` 的消减误差。单点总体标准差为零；空记录拒绝。统计量使用输入单位，原始 counts 仍然可以统计。

### 6.2 地震动强度指标

优先提取 REST IM 中已验证的累积积分与能量百分位计算逻辑，改为独立单通道实现。

| 指标 | 所需输入 | 定义与输出单位 |
|---|---|---|
| PGA | 已知加速度及单位 | `max(abs(a))`，SI 为 m/s²，可显示 g 或 cm/s² |
| PGV | 已知速度及单位 | `max(abs(v))`，SI 为 m/s |
| PGD | 已知位移及单位 | `max(abs(d))`，SI 为 m |
| CAV | 加速度，dt 已知 | `∫ abs(a) dt`，SI 为 m/s |
| Arias 强度 IA | 加速度，dt 已知 | `π/(2g0) * ∫ a² dt`，SI 为 m/s |
| 显著持时 D5–75、D5–95 | 加速度，dt 已知 | 累积平方加速度能量达到指定百分位之间的时长，s |

其中 `g0 = 9.80665 m/s²`，与现有单位定义一致。CAV 采用普通累积绝对加速度积分，不与标准化 CAV 或阈值型指标混淆。能量曲线使用累积梯形积分，从第一个样本处零积分开始；百分位时刻沿累积能量曲线作线性插值，明确平坦区间和端点选择约定。零总能量时 IA 和 CAV 可为零，显著持时物理上未定义，结果标为不可用并说明，不能无条件返回有效零持时。单点记录只有直接峰值和统计意义，积分指标标为不可用或明确说明无积分区间（优先不可用）。

如需要，可以在工程参数页显示归一化累积 Arias 能量曲线及 D5–95 区间，属于对现有计算结果的轻量展示，不作为必须新增的独立分析页面。暂不移植 Housner 强度、仪器烈度、复杂峰值比、规范阈值判定及其他 REST 专用指标。

### 6.3 显式积分估计 PGV/PGD

REST IM 现有方案为累积梯形积分后对速度时程作一阶去趋势，再积分并对位移时程作一阶去趋势。可复用此思路，但不能把它作为所有地震动默认的可靠基线校正。建议提供：

| 选项 | 行为 |
|---|---|
| `none`（默认） | 不从加速度推算速度和位移；直接计算当前输入对应的峰值 |
| `trapezoid` | 以零初始积分值进行累积梯形积分；加速度得到速度与位移，速度得到位移（按适用性） |
| `trapezoid-detrend` | REST 式积分与逐次线性去趋势：每一级积分后去线性趋势，再进入下一级 |

输入单位须明确且可转换至 SI；dt 合法且有足够样本；去趋势至少具有两个不同的样本时刻。若只有很短记录或存在明显积分漂移，给出必要提示，不声称估计值代表实际永久位移。线性去趋势可能改变积分后首值，需注明“积分时零初值”与“最终去趋势曲线首值”不是同一约束。

去趋势和积分不改写原 Trace。估计峰值必须区别于直接读取的 PGA/PGV/PGD，标注 `estimated`/“积分估计”、积分方案及单位。在时程页可按需查看派生速度/位移曲线或导出分析表格，但本阶段不将其注入原波形的转换或批量任务，不作为一个新原始通道。

## 7. M3：频谱分析

### 7.1 频谱定义

提取 MSL 一维 FFT 与 REST 单边频率轴实现；FFT 库采用 Eigen，不重新编写底层 FFT。REST 当前 FFT 频谱返回未归一化的 FFT 模值，不应直接把该结果标为物理幅值。

设有效输入样本数 N，FFT 长度 L（`nfft`），采样率 `fs=1/dt`，可选窗 `w[n]`，`X[k] = FFT(x[n] * w[n], L)`。默认不加窗、不去均值、L=N，允许显式补零，但禁止静默截断。单边频率点 `f_k = k*fs/L`，k 从 0 到 `floor(L/2)`。

| 类型 | 定义 | 纵轴单位 |
|---|---|---|
| FFT 模值 `fft` | `abs(X[k])`，与 REST 未归一化的单边模值定义相同（同样参数时） | 输入幅值单位（未归一化） |
| 单边幅值谱 `amplitude` | `c_k*abs(X[k])/sum(w)`；矩形窗时分母 N | 输入单位 |
| Fourier 幅值谱 `fas` | `dt*abs(X[k])`，连续 Fourier 变换的离散近似，不作双倍折叠 | 输入单位·s |
| Welch 功率谱密度 `psd` | 按下节定义 | 输入单位²/Hz |

对于单边幅值谱，直流及偶数 L 的 Nyquist 点 `c_k=1`，其余具有负频率共轭伙伴的频点 `c_k=2`。奇数 L 的最后一个频点仍需乘 2。补零时归一化分母仍为实际输入窗口系数和，不使用 L 代替 N；补零仅细化频率采样，不提高由有效记录长度决定的真实分辨能力。加窗 FAS 表示加窗后的信号，不自动施加单边幅值谱的窗增益修正。

### 7.2 Welch PSD

复用 MSL 的分段加窗、功率归一化及平均，以及 REST 的单边功率折叠。默认使用对称 Hann 窗（与 MSL `hann_window` 一致），可选矩形、Hamming、Blackman。每段可独立去均值，默认开启；先去均值，再加窗。设分段长度 M、重叠点数 O、FFT 长度 L、完整分段数 K，则：

```text
step = M - O
K = 1 + floor((N-M)/step)
P[k] = c_k/(K*fs*sum(w[n]^2)) * sum_j(abs(FFT(w*x_j)[k])^2)
```

末尾不足一整段的数据不参加 Welch 平均（显示实际段数，不自动补造分段）。参数约定：

- 自动分段长度 `min(4096, N)`，重叠点数 `floor(M/2)`，L 默认等于 M；实际参数在结果中记录。
- N 至少为 2；对默认对称 Hann 窗的 M=2 零窗能量情形，自动模式可明确退回矩形窗并报告实际窗口；显式指定零能量窗口则拒绝。检查合法分段长度、`0 <= O < M`、L>=M、有限正窗能量及合法采样率。
- 允许显式设置窗口、分段、重叠、NFFT 和去均值，不引入自动优化或互谱矩阵。对于显式无效参数报错，不悄悄修正。
- 频率分辨率 `fs/L`（频点间距）、窗口类型、有效记录/分段长度、段数及去均值状态可见。直流、Nyquist、奇偶 L 的单边折叠规则与上节一致。

### 7.3 显示与计算要求

频谱页支持线性频率轴、对数频率轴及适用的线性/对数纵轴；对数显示时不绘制非正值（例如 DC 或零谱值），明确提示，仅改变显示，不修改或丢弃导出数据。不用任意 epsilon 替换零值。默认线性坐标，单位与谱类型同步更新。支持全频段与局部缩放，图形横轴为 Hz；纵轴标签区分 FFT 模值、幅值谱、FAS 和 PSD。

对于极大 NFFT/极短 dt 等可能造成异常资源占用或溢出的输入，在分配和计算前检查长度、整数转换、有限性并设定合理资源上限；报告具体限制，不无声降采样。后台计算使用实际原始 Trace 样本，不使用绘图概览包络作为数值输入。

## 8. M4：反应谱

### 8.1 方法和复用范围

采用 REST Dynamics 的 FOH（First-Order Hold）实现作为基准，而不是较早 IM 中的 Newmark-β。对单位质量单自由度系统：

```text
u'' + 2*ξ*ω*u' + ω²*u = -ag(t)
ω = 2π/T
z = [u, u']^T
z[k+1] = Ad*z[k] + B0*ag[k] + B1*ag[k+1]
```

原实现通过 4×4 增广矩阵指数、尺度变换和输入端点系数计算 FOH 递推矩阵，支持非负阻尼（包括临界、过阻尼）。保留其稳定化和非有限结果检查；只移植必要系数计算及单通道状态推进，不引入 REST Dynamics 的矩阵组装、结构模型、错误码或多通道求解系统。每一周期系数只计算一次，推进时只需当前状态及峰值，不存整套周期响应时程。若采用等价的标量递推，须说明与参考实现的等价性及边界验证，不为减少一个依赖而重新推导未验证的方法。

### 8.2 结果定义

| 输出 | 定义 | SI 单位 |
|---|---|---|
| Sd | `max(abs(u))` | m |
| Sv | `max(abs(u'))`，相对速度 | m/s |
| Sa | `max(abs(-ω²*u - 2*ξ*ω*u'))`，真实绝对加速度 | m/s² |
| PSV | `ω*Sd` | m/s |
| PSA | `ω²*Sd` | m/s² |

以零初始相对位移、速度为条件；有限 T 时初始真实绝对加速度为零，地震动在相邻采样点之间按线性变化，状态递推在该假设下进行。峰值仅在输入的原始采样边界提取（含初始状态），不是采样点之间的连续极值，不自动细分时间步、补零延长自由振动尾段或调整基线。对极短周期与较大 `dt/T` 提示峰值可能欠采样，不静默删去用户周期；可在 README 说明此限制。

T=0 使用明确约定：Sd、Sv、PSV 为 0；Sa、PSA 为 PGA。不得在零周期直接计算 `ω=2π/T`。当输入仅有一个样本时，本阶段优先拒绝反应谱计算并说明至少需要一个有效时间区间，避免用有限周期全零结果误导用户；这属于相对于 REST 的输入限制，需记录。

### 8.3 参数及可用性

- 仅接受物理量为加速度且具有已知可转换加速度单位、有效 dt、有限样本的 Trace；转换至 SI 临时数据。未标定 counts、速度、位移及未知单位不可直接计算反应谱。
- 默认阻尼比 0.05（GUI 显示 5%），默认周期 0–5 s、步长 0.02 s（包含 0、5，共 251 点）。提供可调周期起止、步长与阻尼比；明确阻尼百分数显示与内部小数之间的转换。
- 周期有限非负，步长有限正，最大周期不小于最小周期；零阻尼有效，临界/过阻尼如支持应与原算法保持一致。生成周期序列用整数步索引而非反复累加浮点数，避免多一个或少一个端点；如果最大值不在步长网格上，明确采用不超过最大值的规则。
- 防止周期点数乘样本数引起不可控计算量，检查参数生成上限、非有限系数、传播结果、PSV/PSA 溢出；后台计算可显示进度，取消优先在周期之间协作式停止，取消结果不得当作完整谱导出。
- 图形页允许选择五种结果分别查看；不把单位不同的谱值无说明地叠加在同一纵轴。真实 Sa 与 PSA 始终使用不同标签，默认建议展示 Sa。结果导出同时保留全部五种谱值和参数。

复用现有 `background_task.hpp` 与 Qt Concurrent 机制；统计是否后台执行根据实际规模决定。耗时 FFT、Welch PSD 和反应谱在后台执行。Core 不访问 QWidget；结果、进度、错误在 GUI 线程消费。

- 使用可靠的只读数据所有权（例如共享持有 ReadResult 的不可变分析快照或必要的单 Trace 副本）；不为每种分析复制全文件。禁止在后台任务使用可能因重新解析、编辑、关闭而失效的 span 或指针。采用模态窗口或其他明确的生命周期控制，避免主窗口同时修改分析源。
- 快照包含源通道标识、采样/单位及参数版本；切换通道、修改参数、关闭窗口时，不能让旧任务结果覆盖当前页面。简单方案可在计算期间禁用通道和参数切换，任务结束恢复。
- 对 FFT 等不可中途取消的库调用，说明在安全计算边界结束；对反应谱按周期、Welch 按分段提供可行的协作式取消。取消或失败后不展示未完成结果为成功，不允许导出为完整结果。
- 禁止直接终止线程。关闭/Esc 路径必须处理任务生命周期；后台任务不能访问已销毁窗口。控制进度通知频率，不在每次样本循环发送事件。
- 默认单任务执行，不引入分析线程池、任务数据库或持久化缓存。

## 11. M7：CLI 与分析结果导出

### 11.1 CLI 设计

保留 `formats`、`info`、`convert`、`batch` 的现有语义，新增一个轻量 `analyze` 子命令。读取和标定沿用原有解析参数及 Profile v1；若支持 `--preset`，仅显式复用其读取规则，明确不使用其中写出格式、单位、筛选或覆盖许可。不要将分析参数塞入现有转换预设 schema，也不为每个算法建立单独 CLI 程序。

建议用法（以实现后 README/help 为准）：

```sh
# 不指定通道时仅允许单 Trace 输入；多通道文件必须明确指定 1-based 索引
# 基本统计与工程指标输出 JSON
gmtools analyze record.at2 --channel 1 --type stats
gmtools analyze record.at2 --type intensity --integration trapezoid-detrend

# 频谱与反应谱输出独立 CSV
gmtools analyze record.at2 --type fas -o analysis/fas.csv
gmtools analyze record.at2 --type psd --nperseg 2048 --overlap 0.5 -o analysis/psd.csv
gmtools analyze record.at2 --type response --damping 0.05 --period-min 0 --period-max 5 --period-step 0.02 -o analysis/response.csv

# Modified：先标定，再计算明确选中的加速度通道
gmtools analyze station.mseed --format modified-mseed --channel 1 --calibration source --type response -o analysis/response.csv
```

建议类型稳定标识 `stats|intensity|fft|amplitude|fas|psd|response`。通过现有解析器或局部共享读取参数逻辑，避免复制独立 Reader。分析专有参数仅对适用类型有效；明确拒绝无效、重复或互斥参数。`--channel` 应按已有接口语义选择实际 Trace，不默认猜选加速度通道。多 Trace 未指定索引时清晰报错，禁止无提示地只分析第一条或将多条拼接。

统计及强度可默认输出结构化 JSON 至 stdout（或明确指定 `-o`）；频谱和反应谱优先要求指定 CSV 文件路径。诊断发送 stderr，失败非零退出，无效计算或取消不得生成完整结果文件。输出覆盖必须显式授权。具体 CLI 参数可依据现有代码调整，但必须同步更新文档和 help。

### 11.2 独立分析结果格式

频谱的 X 轴为频率，反应谱的 X 轴为周期，统计量也不是时程，因此不得直接伪装成等间隔 Trace 后通过原波形 Writer 导出。新增简单的分析结果序列化与写出函数，复用 Core 的安全路径、暂存及原子发布辅助逻辑（按需要小范围提取）。不扩展原 FormatId、Reader 注册表或自描述波形 v1。

建议曲线 CSV 格式使用一行版本/类型标记及单行 JSON 注释头（例如 `# GMTools analysis 1` 与 `# {...}`），随后为稳定列名及数据行；JSON 保存源通道、样本数、dt、当前量/单位、实际分析参数、算法方法、结果各列单位及约定。可另支持不带注释的纯 CSV，但元信息版本优先；文档说明 `#` 注释的解析方法。示意：

```text
# GMTools analysis 1
# {"type":"response","damping_ratio":0.05,"method":"foh","peak_sampling":"sample_boundaries","units":{"period":"s","sd":"m","sv":"m/s","sa":"m/s2","psv":"m/s","psa":"m/s2"}}
period,sd,sv,sa,psv,psa
0,0,0,1.2,0,1.2
...
```

以上数据仅为格式示意。频谱导出 `frequency,value`，附实际 FFT、窗、归一化、分段参数及单位；统计/工程指标采用 JSON（可选普通两列/多列 CSV），明确不可用及估计状态、方法和单位。派生积分时程采用 `elapsed_time,velocity,displacement` 等适用列，注明积分方案，不伪造不可用列。数值精度默认保持 double 往返所需精度；导出全量计算结果，不采用屏幕抽稀点、不随对数显示移除 DC/零值，不因视口缩放截断结果。

所有导出必须保护源文件及现有目标；默认不覆盖。GUI 图形输出同样不得覆盖原件或未经同意的外部目标。不要引入整套报告生成系统。

### 11.3 图形导出

GUI 至少支持将当前图形保存为 PNG（使用现有 Qt 渲染能力），保留轴标题、单位、刻度、图例/计算类型；保证实际范围与界面一致，并注明图形导出与全量数据导出的区别。允许按现有能力选择清晰尺寸或 DPI；PDF/SVG、复杂排版、多图报告不作为本轮要求。图片生成仅是用户明确点击功能后的行为，开发过程中不自行启动 GUI 或截图做视觉检查。

## 13. 验收方案及完成定义

### 13.1 验收原则

优先采用少量具有独立参考值的合成信号、现有真实记录和 REST 参考结果，重点验证移植、归一化、单位与接口适配。不要因新增算法而建立庞大的测试框架。可将必要核验整理为一个精简的可选脚本（例如 `scripts/verify_analysis.py`），也可在现有核验脚本中增加少量独立检查；Python、NumPy、SciPy、ObsPy 等仅作为可选验收依赖，不进入运行依赖。

以下用例是验收设计，并非授权自动运行。未经用户明确授权不运行测试、GUI 或截图；必要静态检查与编译可以进行，并记录具体命令和结果。只对实际运行、具有参考依据的用例标记 PASS；缺依赖/样本为 BLOCKED/SKIPPED，未运行标为 NOT RUN。不要用程序自写自读或同一实现的输出作为全部独立证据。

### 13.2 最小验收用例

| 编号 | 核验内容 | 通过条件 |
|---|---|---|
| T0 | M0 多通道发布、筛选、预设状态 | 单/批量三通道均完整发布；原件不变、冲突拒绝、无匹配零输出；GUI 取消/回退及无单位预设恢复正确（人工） |
| T1 | 构建及转换回归 | 精简 CLI 与 GUI 构建；可用时完整 libmseed 构建；原 Profile、转换预设、文本及标定逻辑不变，正常安装可加载翻译 |
| T2 | 基本统计 | 短向量、单点、零信号与未知 dt/单位的统计正确；峰值并列取首次；原始数据不变 |
| T3 | 强度与积分 | 常值加速度在有效时间跨度内的 CAV、IA、D5–75/D5–95 与解析值一致；零能量持时不可用；SI 与 g/cm/s² 输入结果等价；明确验证积分方案与估计标签 |
| T4 | FFT/FAS/单边幅值 | 整周期正弦峰频、幅值、直流与 Nyquist、奇偶 NFFT 的折叠和补零归一化正确，与 NumPy 或独立离散变换对照 |
| T5 | Welch PSD | 与相同对称窗、分段长度、去均值、重叠、FFT 长度的独立参考一致；Parseval 功率检查；短记录及非法窗口诊断正确 |
| T6 | FOH 反应谱 | 与 REST 固定版本或独立解析/数值参考比较 Sd/Sv/Sa，PSV/PSA 定义、零周期、零输入、至少一个非零阻尼和零阻尼条件；单位换算一致 |
| T7 | CLI 与结果导出 | 明确通道选择、参数校验、CSV/JSON 内容、全量数据、分析结果类型与单位明确；禁止覆盖输入；错误非零退出 |
| T8 | GUI 与实际使用 | 双语及主题、时程/频谱/反应谱/工程参数页，缩放与光标、参数失效、后台切换/取消、导出及源数据不变；由用户或明确授权后实际核查 |

合成数据参考示例：

- 统计：`[1,-2,3,-3]`，绝对峰值 3，首次位于第 3 点，均值 -0.25，总体方差 5.6875，RMS 为 `sqrt(23/4)`。
- 常值加速度 `a=A`（SI）且 `N>=2`，跨度 `D=(N-1)*dt`：CAV=`abs(A)*D`，IA=`π*A²*D/(2*g0)`，非零时 D5–75=`0.70*D`，D5–95=`0.90*D`；原始梯形积分速度末值 `A*D`、位移末值 `A*D²/2`。去趋势后结果应按实际拟合方案单独核对，而不是沿用未去趋势解析值。
- FFT：选择 N 点整周期正弦 `x[n]=A*sin(2π*m*n/N)`，`0<m<N/2`。矩形窗、L=N 时，单边峰频 `m*fs/N`、FFT 模值 `N*abs(A)/2`、单边幅值 `abs(A)`、FAS=`dt*N*abs(A)/2`；另用常值、Nyquist 交替序列确认不错误乘 2。
- PSD：固定窗和分段配置，参照 NumPy/SciPy 时传入完全相同的窗系数（不要混用周期 Hann 与对称 Hann），去均值设置一致。单边 PSD 对频率 bin 求和乘频点间距，应对应分段加窗后的归一化平均功率，而不是任意记录未经加窗的整体 RMS²。
- 反应谱：零信号五种结果均为零；T=0 的 Sa、PSA 与 PGA 一致；非零正弦或短分段线性输入对照 REST Dynamics 参考或高精度独立积分，在相同初值、时间范围和原采样边界取峰。不要将连续极值或自由振动尾段结果直接作为原方法误差。
- 真实数据：优先 Helena AT2（5093 点、dt 0.01 s）验证工程指标及谱；Trinidad 使用既有 Profile；花莲、武汉记录在样本与依赖可用时验证多通道、标定和计数通道限制。不下载许可不明的外部记录，不提交大型派生数据或日志。

数值比较应明确容差及原因：基础统计和 FFT 与独立双精度参考可采用合理绝对/相对容差（例如相对 1e-9、按幅值尺度设绝对容差）；FOH 采用参考实现的数值特性与周期、阻尼范围确定容差。不得放宽容差掩盖单位错误、归一化错误或真实/伪反应谱混淆。与不同算法结果比较时明确计算方法差异。

## 14. 实施顺序与交付提醒
